# Edit style: rules for every performance film

Read before making or revising any draft (docs/performance-film.md has the format). Add a rule here when a
comment applies to every film, not just one, so the same note never needs giving twice.

## Names and consent
- Name a participant only when their release allows it; otherwise "Participant 1", "Participant 2"… in the
  order they started.
- Never use anyone's footage, voice or photo beyond what their consent covers.

## The score
- Plain white type on black. Date and time, who was in the booth, who took part.
- The instructions as performed, in order, with the time each was given. Show the written Program beside it when
  the performance ran from one.

## The footage
- Time order. Earpiece speech (Mother, the director) is always captioned in the earpiece style, set apart from
  what participants say aloud.
- Favour the camera that shows the person speaking or acting; avoid the Mac camera unless it's the only view.
- Draft 1 keeps everything meaningful; tighten from comments.

## The debrief
- Audio only, over the portraits' carousel; the ring turns to whoever is talking and holds while they speak.
- Title top-left in white capitals: `DEBRIEF: <DATE>`.
- Use the studio's portrait when there is one, otherwise the registration photo.
- No debrief: end on a closing card.
